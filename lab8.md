# Лабораторная работа №8 - ФИО

## Цель
Изучить основные шаблоны, приводящие к утечкам памяти в веб-приложениях при работе с DOM-деревом и обработчиками событий.

---

## Сценарий 1: Забытые обработчики событий
**Действия:**
1. Нажали кнопку «Запустить» → добавились карточки с обработчиком на `window.scroll`.
2. Удалили карточки кнопкой «Очистить», но обработчики не снялись.
3. Сняли Heap Snapshot до и после удаления карточек.
4. Использовали «Retainers» для поиска удерживаемых объектов.

**Вывод:**  
Объекты карточек удерживаются глобальными обработчиками событий на `window`. Сборщик мусора не может их удалить, пока обработчики не будут сняты.  
**Устранение:** использовать `removeEventListener` при удалении карточек.

---

## Сценарий 2: Сохранение DOM-узлов в глобальных структурах
**Действия:**
1. Нажали кнопку «Запустить» → карточки добавились и ссылки на них сохранились в глобальном массиве.
2. Очистили контейнер кнопкой «Очистить» (DOM удалён, но массив не очищен).
3. Сняли Heap Snapshots → элементы всё ещё в памяти.

**Вывод:**  
Ссылки на DOM-узлы в глобальном массиве препятствуют сборке мусора.  
**Устранение:** очищать массив после удаления элементов из DOM.

---

## Сценарий 3: Утечка через замыкания (closures)
**Действия:**
1. Нажали кнопку «Запустить» → создаются карточки и таймеры с `setInterval`, которые используют DOM-элементы.
2. Удалили карточки кнопкой «Очистить» (DOM исчез, таймеры не остановлены).
3. Сняли Heap Snapshots → элементы всё ещё удерживаются через замыкания таймеров.

**Вывод:**  
Замыкания таймеров продолжают ссылаться на удалённые DOM-элементы, что блокирует GC.  
**Устранение:** хранить ID таймеров и вызывать `clearInterval` при удалении элементов.

---

**Общий вывод:**  
Все сценарии демонстрируют классические утечки памяти в веб-приложениях. Для предотвращения необходимо:  
- снимать обработчики событий, привязанные к DOM;  
- очищать глобальные ссылки на DOM;  
- прекращать работу таймеров, которые используют удалённые элементы.  

С помощью техники «трёх снимков» можно точно выявить утечки и понять механизм удержания объектов.
